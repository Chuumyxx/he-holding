HE HOLDING — PAKET LENGKAP V6 (ICON CACHE-BUST)

Unggah SEMUA file dalam paket ini ke root repository he-holding, timpa file lama, lalu Commit changes.
Versi ini memakai nama file ikon baru berakhiran v2 agar Chrome tidak menganggap URL ikon lama masih sama.

Setelah GitHub Pages selesai:
1. Buka https://chuumyxx.github.io/he-holding/ di Chrome Android.
2. Buka https://chuumyxx.github.io/he-holding/manifest.json dan pastikan ikon mengarah ke he-holding-icon-192-v2.png serta he-holding-icon-512-v2.png.
3. Jika aplikasi pernah di-install sebagai PWA: buka Setelan Android > Aplikasi > Cek Aktual/HE HOLDING > Penyimpanan > Hapus cache (jangan hapus data dulu jika ada data penting).
4. Tutup paksa Chrome dan aplikasi web, lalu buka ulang situs.
5. Jika masih memakai ikon lama, buka Chrome `about://webapks` di address bar Android, cari HE HOLDING/Cek Aktual, tekan Update jika tersedia; kemudian jalankan dan tutup aplikasinya.
6. Hapus shortcut lama dari layar utama dan install/tambahkan lagi dari menu Chrome. Pilih Install jika tersedia, bukan hanya Create shortcut.

Catatan: Chrome Android memperbarui ikon PWA melalui siklus pembaruan WebAPK. Pembaruan manifest tidak selalu langsung terlihat; perangkat mungkin perlu tersambung Wi-Fi dan pengisian daya.
Data aplikasi tersimpan lokal. Sebelum menghapus data aplikasi, pastikan data yang diperlukan sudah dicatat/diamankan.
